# 豆包即梦 Seedance 2 Prompt Studio

面向新手的 Seedance 2 提示词可视化工作台，完全免费使用。

## 功能特点

- **极简模式**：一句自然语言描述，自动生成分段提示词
- **进阶模式**：分时段编辑画面/动作/运镜/音频
- **模板预置**：短剧片段、产品广告、科普动画、自定义模式
- **规则校验**：素材超限、引用模糊、镜头冲突智能检测
- **AI 增强**：支持 OpenAI 兼容 API 增强生成
- **导出能力**：复制提示词、下载 TXT、导出 JSON
- **本地存储**：自动保存编辑状态，数据不出本地

## 使用方法

1. 选择模板类型（短剧/广告/科普/自定义）
2. 输入视频时长（4-15秒）
3. 在极简模式下用自然语言描述你想做的视频
4. 点击「一键生成」获得完整提示词
5. 复制到 Seedance 2 使用
